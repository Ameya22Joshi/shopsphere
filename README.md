# ShopSphere

An end-to-end e-commerce backend engineering learning project built progressively with Python and FastAPI.

## Project objective

Understand how modern backend systems are planned, designed, implemented, tested, deployed, monitored, and scaled.

## Learning approach

For each feature:

1. Identify the problem and gather requirements.
2. Define acceptance criteria and constraints.
3. Explore alternatives and document design decisions.
4. Implement in small, reviewable increments.
5. Test behavior and failure scenarios.
6. Measure results where relevant.
7. Document lessons and commit changes to Git.

## Planned technology stack

- Python, FastAPI, Uvicorn
- PostgreSQL, SQLAlchemy 2.0, Alembic
- JWT-based authentication and password hashing
- Redis
- RabbitMQ and Celery
- Nginx
- Docker and Docker Compose
- Kubernetes (Minikube or k3d)
- k6
- Prometheus and Grafana
- GitHub Actions, pytest, and Ruff

Technologies will be introduced incrementally, not all at once.

## Project status
